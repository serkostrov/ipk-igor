# AGENTS.md

1. Код должен быть правильным, професиональным, простым, читаемым, типизированным, единообразным и идиоматичным. Избегай лишней сложности и абстракций, перегруженых функций.

2. Перед созданием нового кода изучи проект. Если похожая реализация есть - переиспользуй её. Не создавай дубликаты.

3. Строго соблюдай Feature-Sliced Design. Не смешивай слои и их ответственность. Выстраивай удобную и понятную иеерархию/архитектуру.

4. Переиспользуй строго существующие компоненты(из проекта, из shadcn), логику, хуки, утилиты и паттерны проекта если таковые имеются. Используй принцип: сначала изучи → переиспользуй → упрости → только потом создавай новое.

5. UI и UX должны быть красивым, удобным, понятным, не перегруженым, единообразными во всём приложении. Используй палитру строго по теме.

6. Бизнес-логику отделяй от UI. Каждый модуль должен отвечать только за свою ответственность.

7. Не дублируй состояние, логику и данные без необходимости.

8. Не изменяй unrelated-код и не делай лишний рефакторинг.

9. Используй supabase и все его функции как backend.

10. Перед завершением проверь типы, ошибки(npm run prepare) и соответствие существующим паттернам проекта.

Главное правило: **професионально, чисто, красиво, удобно, просто, единообразно, предсказуемо, без дублирования**



Не при каких обстоятельствах не меняй содержимое файла AGENTS.md.
