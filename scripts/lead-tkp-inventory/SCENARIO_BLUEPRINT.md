# Blueprint: сценарии лид → Разбор ТКП (эталон ТЗ)

Стенд на момент инвентаризации **не содержит** шаблонов 1–13 (только stub «Новая задача» на одном процессе лида). Этот файл — чеклист для ручной настройки в `/settings/automations` или seed после выгрузки field id.

## Процессы

| Сущность   | Trigger field | Release                                   |
| ---------- | ------------- | ----------------------------------------- |
| Лид        | Стадия (list) | sequential на шагах 2–5                   |
| Разбор ТКП | Стадия (list) | parallel на шаге 7; sequential 8–9 и 12.x |

Дефолт стадии Разбора = **«Создано»** (не «Выбор отделов»).

## Критично для шага 7

```json
{
  "type": "relatedField",
  "linkedChild": {
    "tabId": "…",
    "entityId": "…Расчёты отделов…",
    "parentFieldId": "…"
  },
  "relationFieldId": "",
  "fieldId": "…руководитель…",
  "fanOut": true,
  "completeWhen": "all"
}
```

Без `fanOut: true` после миграции §10 п.6 веер **не** включится по имени сущности.

## Экспорт / импорт

```bash
node scripts/lead-tkp-inventory/export-automation-config.mjs
```

Пишет JSON процессов/сценариев/шаблонов лида и Разбора ТКП в `scripts/lead-tkp-inventory/automation-export.json`.
